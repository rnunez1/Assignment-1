# Personal Home Page - Lab 2.1 Assignment

## Overview
This is a personal home page assignment created as part of Lab 2.1. The project demonstrates HTML fundamentals including semantic structure, links, lists, and text formatting.

## Project Description
A complete, single-page personal website that serves as an introduction to who you are, your interests, goals, and how to contact you. This page showcases HTML best practices and proper document structure.

## Files Included
- `index.html` - Main home page with your personal information
- `README.md` - This file, containing project documentation
- `resume.html` - (Future addition) A relative link to your resume page

## Features Implemented
✅ Proper HTML5 document structure with DOCTYPE, html lang, head, and body  
✅ One main heading (h1) and two additional headings  
✅ Three paragraphs describing yourself  
✅ Use of `<strong>` and `<em>` tags for text emphasis  
✅ One ordered list (goals/priorities)  
✅ One unordered list (interests/hobbies)  
✅ Three hyperlinks:
   - Absolute link to an external website
   - Relative link to resume.html (future page)
   - Email link for contact  
✅ Professional styling with CSS  
✅ Responsive meta viewport tag  

## How to Customize Your Page

### 1. **Update the Page Title**
   - Find: `<title>My Personal Home Page</title>`
   - Replace with: `<title>Your Name - Personal Home Page</title>`

### 2. **Update the Main Heading**
   - Find: `<h1>Welcome to My Personal Home Page</h1>`
   - Replace with: `<h1>Your Name</h1>` or your preferred title

### 3. **Add Your Three Paragraphs**
   - **First Paragraph** (About Me section): Introduce yourself, your background, and interests
   - **Second Paragraph** (About Me section): Discuss your experiences, internships, and achievements
   - **Third Paragraph** (About Me section): Share your goals and aspirations

### 4. **Customize Your Interests List**
   - Replace the four bullet points in the "My Interests and Hobbies" section with your actual interests

### 5. **Customize Your Goals List**
   - Replace the four items in the "My Goals" section with your actual goals in priority order

### 6. **Update the Links**

   **External Link (Absolute URL):**
   - Find: `<a href="https://www.example.com" target="_blank">Visit an External Website (Replace with your choice)</a>`
   - Replace `https://www.example.com` with a real website you want to link to
   - Examples: LinkedIn, GitHub, portfolio site, etc.

   **Resume Link (Relative Link):**
   - This link (`resume.html`) will work once you create a resume page
   - Currently, it's just a placeholder link

   **Email Link:**
   - Find: `<a href="mailto:your.email@example.com">Send Me an Email</a>`
   - Replace `your.email@example.com` with your actual email address

### 7. **Update the Footer**
   - Find: `<p>&copy; 2026 My Personal Home Page. All rights reserved.</p>`
   - Replace with your name and copyright information if desired

## How to Publish on GitHub Pages

### Step 1: Create a GitHub Repository
1. Go to [GitHub.com](https://github.com)
2. Click the "+" icon in the top right and select "New repository"
3. Name it: `Assignment1` (or your preferred name)
4. Add a description: "Personal Home Page - Lab 2.1"
5. Choose "Public" (required for GitHub Pages)
6. Click "Create repository"

### Step 2: Upload Your Files
1. Click "uploading an existing file" on the repository page
2. Drag and drop `index.html` and `README.md`
3. Add a commit message: "Add personal home page assignment"
4. Click "Commit changes"

### Step 3: Enable GitHub Pages
1. Go to your repository Settings
2. Scroll down to "GitHub Pages" section
3. Under "Source," select "main" branch
4. Click "Save"
5. Your site will be published at: `https://yourusername.github.io/Assignment1/`

### Step 4: Validate Your HTML
1. Before submitting, go to [W3C HTML Validator](https://validator.w3.org/)
2. Enter your GitHub Pages URL
3. Fix any errors reported
4. Once validated, you're ready to submit!
